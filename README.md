# IISER Mohali Merchandise Preference Survey 2026

Welcome to the official repository for the **IISER Mohali Merchandise Preference Survey 2026**, conducted by the **Turing Club** (The Computation Club of IISER Mohali). 

This project provides an open-access, empirical data processing and analysis pipeline designed to understand student merchandise preferences. By analyzing quantitative choices and qualitative community feedback, this framework eliminates guesswork, mitigates financial risk for campus clubs and fest committees, and provides actionable guidelines for designing high-demand merchandise.

## 2. Environment Setup

This repository uses [`uv`](https://github.com/astral-sh/uv) for fast, deterministic dependency management, but supports standard `pip` as well.

### Option A: Using `uv` (Recommended)
```bash
# Clone the repository
git clone https://github.com/IISERM/merch-preference-survey-2026.git
cd merch-preference-survey-2026

# Create virtual environment and install dependencies automatically
uv sync

# Run the master analysis script
uv run python3 run_analysis.py
```

### Option B: Using Standard Python `venv` & `pip`
```bash
# Create and activate virtual environment
python3 -m venv .venv
source .venv/bin/activate

# Install dependencies from requirements.txt
pip install -r requirements.txt

# Run the master analysis script
python3 run_analysis.py
```

## 3. Methodology & Analytical Process

The survey dataset was processed using a multi-stage data science pipeline designed to ensure data integrity, reproducibility, and mathematical consistency.

```
       +-----------------------------------------------+
       | Raw Dataset (data/iiserm_merch_survey_data.csv)|
       +-----------------------+-----------------------+
                               |
                               v
       +-----------------------------------------------+
       |             Data Preprocessing                |
       |  - Anonymization & Consent Verification       |
       |  - Multi-Select Delimiter Parsing (';')       |
       |  - Numerical Encoding of Likert Ratings       |
       |  - Qualitative Text Normalization             |
       +-----------------------+-----------------------+
                               |
            +------------------+------------------+
            |                  |                  |
            v                  v                  v
    +---------------+  +---------------+  +---------------+  
    |  Demographics  |  |   Apparel &   |  |   Consumer    |  
    | & Purchasing  |  | Design Matrix |  | Psychology &  |  
    |    Volume     |  | & WTP Pricing |  | Decision Keys |  
    +-------+-------+  +-------+-------+  +-------+-------+  
            |                  |                  |
            +------------------+------------------+
                               |
                               v
       +-----------------------------------------------+
       |             Master Output Pipeline            |
       |               (run_analysis.py)               |
       +-----------------------------------------------+
```

### 3.1 Data Cleaning & Privacy Preservation
- **Anonymization:** Direct identifying information (respondent email addresses) was replaced with unique 4-character hashes (e.g., `2TJ7`, `NNY7`) to maintain complete anonymity.
- **Consent Enforcement:** 100% of analyzed records correspond to respondents who explicitly agreed to the *Data Release & Privacy Consent* guidelines.

### 3.2 Delimited Multi-Select Parsing
- Questions permitting multiple selections (e.g., academic fields, merchandise categories, sizes, themes, and laptop carry methods) store values as semicolon-delimited strings (`Item A;Item B`). 
- The module [`src/data_preprocessing.py`](file:///home/hrsh/projects/merch-preference-survey-2026/src/data_preprocessing.py) parses and explodes these strings into atomic observations to calculate exact respondent percentages ($P = \frac{\text{Count}}{N} \times 100$, where $N=55$).

### 3.3 Numerical Likert Scale Encoding
To compute meaningful central tendency and dispersion metrics (Mean score $\mu$ and Standard Deviation $\sigma$), discrete categorical scales were mapped to numerical vectors:
1. **Apparel Design Placement Scale (3-Point):**
   $$\text{Not Preferred} \rightarrow 1, \quad \text{Preferred} \rightarrow 2, \quad \text{Highly Preferred} \rightarrow 3$$
2. **Purchase Decision Drivers Scale (5-Point):**
   $$\text{Not at all} \rightarrow 1, \quad \text{Low Priority} \rightarrow 2, \quad \text{Maybe/Sometimes} \rightarrow 3, \quad \text{High Priority} \rightarrow 4, \quad \text{Absolutely/Of course} \rightarrow 5$$

## 4. Key Empirical Findings & Insights

### 4.1 Demographic Breakdown
- **Core Population:** Undergraduates (BS-MS) represent 92.5% of respondents. 3rd-year (MS23: 40.7%) and 4th-year (MS22: 25.9%) students form the largest demographic block.
- **Academic Disciplines:** Physics (61.8%) and Mathematics (36.4%) represent the highest field interests, followed by Chemistry (34.5%), Biology (30.9%), EES (23.6%), and HSS (18.2%).
- **Purchasing Frequency:** Students purchase an average of **2.07 merchandise items per year** (Median: 2.0, IQR: 1.0–3.0).

### 4.2 Product Demand & Priorities
1. **T-Shirts (Half Sleeve):** 76.4% interest | 27.3% single must-have priority.
2. **Hoodies / Sweatshirts:** 61.8% interest | 23.6% single must-have priority.
3. **Full-Zip Jackets:** 56.4% interest | 12.7% single must-have priority.
4. **Laptop Bags & Sleeves:** 34.5% interest | 12.7% single must-have priority.
5. **Stickers & Plushies:** 36.4% interest each.

### 4.3 Apparel Design Placement & Specification Matrix
- **Back Hero Artwork Rule:** Main "Hero" designs are strongly preferred on the **BACK** (Mean: **2.18 / 3.00**; 83.6% positive) over the FRONT (Mean: **1.71 / 3.00**; 47.3% negative). Front placements should be kept subtle (small chest logo or minimalist text).
- **Branding:** Clear inclusion of **'IISER Mohali'** text/logo is highly favored (Mean: **2.29 / 3.00**; 81.8% positive).
- **Fabric & Cut:** **60.0%** prefer **100% Cotton**. Over 50% of qualitative text feedback explicitly requests **Oversized / Drop-shoulder / Boxy / Baggy fits** rather than standard slim-fit T-shirts.

### 4.4 Pricing & Willingness-To-Pay (WTP)
- **Sweatshirt / Hoodie Corridor:** The optimal pricing window is **500 – 750 INR** (81.8% cumulative willingness to pay up to 800 INR). Pricing items above **800 INR** reduces the potential customer base to under 18.2%.

### 4.5 Consumer Psychology & Decision Drivers
- **Top Decision Keys (1–5 scale):**
  1. *Merch Design & Aesthetic:* **4.56 / 5** (94.5% High/Absolute Priority)
  2. *Quality of Item / Material:* **4.36 / 5** (90.9% High/Absolute Priority)
  3. *Functionality:* **4.36 / 5** (85.5% High/Absolute Priority)
  4. *Personal Budget:* **4.05 / 5** (70.9% High/Absolute Priority)
  5. *Club / Community Brand:* **2.98 / 5** (30.9% High/Absolute Priority)
- **Brand Loyalty Reality:** **90.6%** of respondents stated they **will NOT buy merchandise blindly** based on club identity alone. Quality, design, and pricing remain paramount.

## 5. Summary Guidelines for Campus Clubs & Committees

1. **Prioritize Back-Print Artwork:** Keep the front minimal with subtle chest logos or typography, and place hero artwork on the back.
2. **Modernize Apparel Silhouette:** Shift from standard cut T-shirts to heavy-cotton (240+ GSM), oversized, and drop-shoulder silhouettes.
3. **Cap Hoodie Prices at 750 INR:** Ensure sweatshirts and hoodies remain within the 500–750 INR range for maximum community adoption.
4. **Expand Beyond Clothing:** Explore high-demand niche items such as **Linux Tux Plushies**, **Hostel-specific Metal Keychains**, **Custom Mousepads**, and **Desk Accessories** (e.g., pen holders and field journals).
